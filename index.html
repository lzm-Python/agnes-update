会做什么

图片：1K / 2K，四种比例，最多 3 张参考图，可套 60 种风格
视频：文本 / 首尾帧 / 参考图三种模式，最多 5 张参考图，同样能套风格
剧本：最多 3 张参考图，按提示词自动对号
大字提词器、历史收藏、深浅色切换
写实约束可开关，报错说人话

安装三步

1点上面任意一条下载，得到 AgnesVideo.apk
2点开安装，系统提示“未知来源”时允许一次
3打开后进设置，填自己的 API Key 即可用
