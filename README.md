# Agnes 工作台 · 安装包存档

本仓库保存 Agnes 工作台全部历史版本，同时作为 App 的自动更新源。

- 自动更新源：`version.json`
- 最新版固定下载：`releases/latest/download/AgnesVideo.apk`
- 历史版本：见右侧 Releases

## 说明

- 包名：`com.agnes.video`
- 最低系统：Android 5.0（API 21）
- 签名：自签证书
- 覆盖安装需版本号更高，或先卸载旧版

## 国内访问加速

- 仓库页面镜像：`kkgithub.com/lzm-Python/agnes-update`
- 文件加速：原始链接前加 `https://gh-proxy.com/`
